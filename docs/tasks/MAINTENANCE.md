## Разобрано

- [x] **Страж `db:*` называл не ту цель для `db:seed`.** Заведено 7 сентября 2026,
      разобрано на закрытии фазы 8: переменная выбирается по обёрнутой команде —
      `drizzle-kit` читает `DIRECT_DATABASE_URL`, а потом `DATABASE_URL`,
      приложение знает только `DATABASE_URL`. Обещание «команда называет свою
      цель» снова верно для обеих. Две негативные фикстуры в
      `scripts/db-guard.test.ts`; прежний тест приоритета переписан под новое
      правило, а не удалён.

- [x] **Решения тасков T3.1–T3.3 не были записаны в `docs/08-DECISIONS.md`.**
      Заведено 7 сентября 2026 (фаза 3, T3.4), разобрано на закрытии фазы:
      восстановлены из кода записи P3-34 (дни проживания и день выезда),
      P3-35 (счёт `external` не заводится) и P3-36 (месяц выезда берётся целиком).
      Каждая помечена как записанная задним числом — реконструкция по коду,
      а не воспоминание о том, чего никто не писал.

- [x] **Список пользователей не был разбит на страницы.** Заведено 7 сентября 2026
      (фаза 3, T3.12), разобрано на закрытии фазы: экран `/settings/users` показывает
      страницами по 25 записей. На накопленных прогоном шестистах жильцах перерисовка
      перестала укладываться в ожидание приёмки (инцидент I3); в живой сети столько
      наберётся за пару лет.

- [x] **Молчаливый запасной адрес базы в интеграционных тестах.** Заведено 7 сентября 2026
      (фаза 2, T2.5b), разобрано в конце фазы 2: адрес берётся из `testDatabaseUrl()`,
      запасного значения нет — без переменной прогон падает с внятным текстом.
      Порт 5432 на машине разработчика занят чужим сервером, и молчаливый переход туда
      успел стать инцидентом I2. Сторож `src/db/testing/database-url.test.ts` не даёт
      запасному адресу вернуться ни в один `*.db-test.ts`.

- [x] **Депрекация Node 20 в GitHub Actions.** Заведено 6 сентября 2026 (фаза 1),
      разобрано в конце фазы 1: `actions/checkout` v4 → v7, `actions/setup-node` v4 → v7,
      `pnpm/action-setup` v4 → v6, `actions/upload-artifact` v4 → v7. Предупреждение
      о принудительном запуске на Node 24 в каждом прогоне снято.

- [x] **Плавающие падения интеграционных тестов.** Заведено 7 сентября 2026
      (фаза 4), разобрано на закрытии фазы. Дело оказалось не в чужих данных:
      `monthly-invoices.db-test` брал «первое место дома» запросом без сортировки
      и вставлял новое назначение на чужое место с открытым периодом, а доли
      коммуналки сортировались по времени создания — одному и тому же у всех строк
      транзакции, отчего их порядок оставался на усмотрение планировщика. Место
      теперь берётся у самого проживания, доли идут по числу прожитых дней:
      порядок осмыслен и для человека, который их читает.

- [x] **Подпись договора в приёмке фазы 2 неустойчива под нагрузкой.** Заведено
      7 сентября 2026 (фаза 4), разобрано на закрытии фазы: приёмка ждёт исчезновения
      самой формы подписи, а не текста рядом с ней, и ждёт дольше обычного. Подпись
      уходит файлом, и на загруженной машине шаг не укладывается в общее ожидание;
      форма пропадает ровно тогда, когда файл сохранён.

- [x] **Экран не обновляется после сохранения, если на него пришли по предзагруженной ссылке.**
      Заведено 7 сентября 2026 (фаза 4, T4.3), разобрано на закрытии фазы. Вместо флага
      на каждой ссылке заведена обёртка `@/components/ui/app-link` с выключенной
      предзагрузкой, все двадцать ссылок приложения переведены на неё, а прямой импорт
      `next/link` в компонентах запрещён правилом ESLint с негативной фикстурой.
      Выигрыш предзагрузки не стоит показа устаревших данных: все экраны `force-dynamic`.
