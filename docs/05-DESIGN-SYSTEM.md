# 05. Дизайн-система

Тон: минимализм, строгость, плотная информация. Это рабочий инструмент, а не лендинг.
Запрещено: эмодзи, многоцветные градиенты, декоративные иллюстрации, скруглённые «пузыри»,
тени-ореолы, анимации дольше 200 мс, иконки разной толщины линий.

## Цвет: пропорция

Фирменные цвета — синий `#004AAD` и жёлтый `#FEE274` — работают только как акценты.
Основную площадь занимают нейтрали.

| Доля | Роль |
|---|---|
| ~75 % | фон и поверхности (белый / почти чёрный) |
| ~15 % | текст, границы, приглушённые элементы |
| ~8 % | синий: первичные кнопки, ссылки, активное состояние, выделение строки |
| ~2 % | жёлтый: маркер «сегодня», бейдж «требует внимания», второй ряд графиков, подсветка активной вкладки |

### Жёсткие правила контраста (проверено расчётом)

- `#004AAD` на белом: **8,1 : 1** — годится для текста и кнопок. Белый текст на `#004AAD`: 8,1 : 1.
- `#FEE274` на белом: **1,3 : 1** — **нечитаемо**. Жёлтый **никогда** не текст на светлом фоне
  и никогда не заливка крупной кнопки.
- Текст `#0B0B0C` на `#FEE274`: **15 : 1** — единственный допустимый способ использовать жёлтый
  как заливку: маленький бейдж с почти чёрным текстом.
- В тёмной теме `#004AAD` на тёмном фоне даёт ~1,6 : 1 — **нельзя**. Первичный синий
  в тёмной теме осветляется до `#4C8DF6` (5,9 : 1).

Минимум для основного текста — 4,5 : 1, для крупного и иконок — 3 : 1. Проверять каждый экран.

## Типографика

Montserrat через `next/font/google`, веса 400 / 500 / 600 / 700, `display: swap`, латиница + кириллица.

| Роль | Размер / вес |
|---|---|
| H1 | 28 / 600, tracking −0.01em |
| H2 | 22 / 600 |
| H3 | 18 / 600 |
| Body | 15 / 400, line-height 1.55 |
| Small, подписи | 13 / 400 |
| Метка таблицы | 12 / 600, uppercase, tracking 0.04em, `--text-muted` |
| Числа и деньги | `font-variant-numeric: tabular-nums`, выравнивание вправо |

Montserrat узкий в нижнем регистре — не используй его для длинных абзацев мельче 15px.

## Сетка и адаптивность

Точки: `sm 640`, `md 768`, `lg 1024`, `xl 1280`.

- **Мобильный (< 768)**: одна колонка, нижняя навигация из 4 пунктов + «Ещё»,
  таблицы превращаются в карточки, календарь ротаций — режим «день» по умолчанию,
  все интерактивные цели не меньше 44×44 px.
- **Планшет (768–1023)**: две колонки, боковое меню сворачивается в иконки,
  календарь — режим «неделя».
- **Десктоп (≥ 1024)**: постоянное боковое меню 240 px, таблицы полностью,
  календарь — «месяц», модалки до 720 px.

Мобильный макет проектируется первым. Каждый экран проверяется на 375 / 768 / 1440.

## Компоненты (`src/components/ui`)

`Button` (primary / secondary / ghost / danger, размеры sm/md), `Input`, `Select`,
`Combobox`, `DatePicker`, `Textarea`, `Checkbox`, `Switch`, `Badge`
(neutral / info / success / warning / danger / accent), `Card`, `Table` (с липкой шапкой,
сортировкой и мобильной карточной раскладкой), `Modal`, `Drawer`, `Tabs`, `Toast`,
`EmptyState`, `Skeleton`, `Pagination`, `Avatar`, `Money`, `StatusPill`, `SignaturePad`,
`FileUpload`, `Calendar` (день/неделя/месяц с drag-and-drop), `ChecklistEditor`.

Поведенческие примитивы — Radix UI. Иконки — lucide-react, размер 16/20, толщина 1.5.

## Состояния и обратная связь

Каждый список имеет: загрузка (skeleton), пусто (`EmptyState` с действием), ошибка (повтор).
Формы: валидация на blur и на submit, ошибка под полем, кнопка блокируется на время отправки.
Опасные действия (расторжение, сторно, отмена штрафа, закрытие периода) — модалка
с подтверждением и явным описанием последствий.

## Статусы: цветовой код

| Статус | Цвет |
|---|---|
| Оплачен, выполнена, одобрено | success |
| Выставлен, запланирована, на проверке | neutral |
| Требует внимания, истекает, ожидает решения | accent (жёлтый бейдж, тёмный текст) |
| Долг, не выполнена, отклонено, сожжён | danger |
| Отменена, архив | muted |

## Доступность

Фокус видим всегда (кольцо 2 px `--primary`). Навигация с клавиатуры по всем формам и таблицам.
`aria-label` у иконочных кнопок. Не передавать смысл одним лишь цветом — дублировать текстом.
