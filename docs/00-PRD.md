# 00. Продукт

## Что это

Внутренняя система сети студенческих домов **Nice Almaty**. Заменяет ручное ведение
дежурств, оплат и депозитов в тетрадях и группах WhatsApp.

Не публичный сервис: аккаунты создаются только суперадмином, самостоятельной регистрации нет.

## Пользователи и роли

| Роль | Кто | Доступ |
|---|---|---|
| **Суперадмин** | владелец сети | всё по всем домам; создаёт дома, админов и жильцов; настраивает правила; ведёт бухгалтерию; отменяет штрафы |
| **Админ** | админ одного дома (сам живёт в доме) | все данные жильцов **своего** дома; расписание ротаций, оценки, счета, коммуналка, ущерб, инвентарь дома. Чужие дома невидимы полностью |
| **Жилец** | студент | только свои данные: профиль, документы, депозит, счета, ротации, отсутствия, свой рейтинг (как число, без детализации) |

Правила ролей:
- Один админ — один дом. Суперадмин может делать всё, что админ, в любом доме.
- Админ — одновременно жилец: у него есть место (обычно с ценой 0), он участвует
  в комнатных и генеральных ротациях, но не в ротациях общих зон, и платит коммуналку.
  Поэтому **роль и проживание — разные сущности**.
- Суперадминов может быть несколько, с равными правами.

## Глоссарий

| Термин | Значение |
|---|---|
| **Сеть (org)** | владелец нескольких домов. Сейчас одна, создание новых сетей в UI выключено, но `org_id` есть везде |
| **Дом (house)** | физический дом |
| **Зона (area)** | помещение дома. Тип `living` (жилая комната) или `common` (общая зона: двор, кухня, туалет 1, зал…) |
| **Место (bed)** | спальное место в жилой комнате: ярус (верх/низ), номер, цена по умолчанию |
| **Проживание (residency)** | связь «жилец ↔ дом ↔ место» с датами договора, статусом, ценой |
| **Ротация** | одно дежурство: зона + дата + исполнитель(и) + чек-лист |
| **Ряд (row)** | группа мест и зон, привязанная к дню недели, внутри которой ротации идут циклом |
| **Генеральная уборка** | ротация типа `general`, последнее воскресенье месяца, участвуют все |
| **Депозит** | 45 000 ₸ по умолчанию, лежит на депозитном счёте жильца, из него гасится ущерб |
| **Ущерб** | трата на ремонт, разделённая между депозитами выбранных жильцов |
| **Удалёнка** | задача админу: отправить жильцу счёт на оплату дистанционно через Kaspi и получить перевод |
| **Рейтинг** | число 0–100, старт 50, сбрасывается 1 июля. Меняется от оценок уборок и действий админа |

## Границы первой версии

Входит: 11 модулей из `docs/04-MODULES/`, три локали, две темы, PWA с push-уведомлениями,
документированный REST API, экспорт CSV/XLSX, бухгалтерия двойной записи, инвентарь.

Не входит (задел в коде, но не реализуется):
- WhatsApp-бот (существует отдельно; здесь только адаптер-заглушка канала и API для него)
- ЭЦП (сейчас — нарисованная подпись как дублёр бумажного договора)
- Платёжная интеграция Kaspi (способ оплаты отмечается вручную)
- SMS и e-mail
- Создание новых сетей через UI

## Критерий готовности продукта

1 сентября админ дома ведёт **весь** цикл в системе и не открывает тетрадь:
заселил, выставил счета, составил ротации на месяц, проставил оценки, посчитал коммуналку,
списал ущерб, увидел рейтинг. Жилец с телефона подтверждает уборку и подаёт отсутствие.
