# Модуль 1. Профиль, договор, заселение и выселение

Расчётные правила — `docs/03-BUSINESS-RULES.md` §1, §2.

## Экраны

### Жилец
- **Мой профиль** — форма: Фамилия, Имя, Отчество, пол, номер телефона, дата рождения,
  номер УДЛ, ИИН, университет, курс, major, экстренный контакт (имя, телефон, кем приходится),
  предпочтительный способ оплаты (Kaspi / Наличные).
  Комната и Место — только чтение, заполняет админ.
  ИИН и номер УДЛ вводятся один раз, дальше показаны замаскированными.
- **Мастер заселения** — прогресс-шаги: профиль → место → договор → документы → депозит.
  Каждый шаг с явным статусом и кнопкой действия. Пока шаг не закрыт, остальные модули недоступны.
- **Договор** — просмотр PDF, поле для рисования подписи (canvas, экспорт PNG),
  кнопка «Подписать». После подписания — скачивание PDF с подписью.
- **Документы** — карточки типов: загрузить, статус проверки, срок действия,
  причина отклонения. Для флюорографии — обязательное поле «дата снимка».
  Чекбоксы «нет эпилепсии», «нет астмы» с фиксацией даты подтверждения.
- **Депозит** — сумма, статус счёта, движение (все начисления и списания за год с описанием).

### Админ / Суперадмин
- **Список жильцов дома** — фильтры по статусу, комнате, наличию долга, просроченным документам.
  Колонки: ФИО, комната/место, статус, рейтинг, долг, документы (индикатор).
- **Карточка жильца** — профиль (редактируемый), место и цена, договор, документы с кнопками
  «Принять»/«Отклонить», депозит, счета, ротации, рейтинг, история.
- **Создание аккаунта** (только суперадмин) — телефон, дом, роль, генерация временного пароля
  с кнопкой «Скопировать». Пароль показывается один раз.
- **Расторжение договора** — модалка: дата выезда (по умолчанию сегодня, можно будущую),
  причина, подтверждение. Далее — экран расчёта: остаток депозита, проведённый ущерб,
  счётчик «дней до возврата», кнопка «Создать счёт возврата».

## Правила

- Жилец не может менять: комнату, место, цену, статус, даты договора.
- Админ и суперадмин могут менять любой пункт профиля; каждое изменение — в `audit_log`.
- Кнопка «глаз» раскрывает ИИН/УДЛ; факт раскрытия логируется.
- «Ключи выданы» — отдельная отметка, не блокирует ничего, но видна в списке.
- Суперадмин может добавить новый тип обязательной справки — он появляется у всех жильцов
  всех домов со статусом «требуется», с уведомлением.
- При расторжении: доступ ко всем модулям кроме профиля и депозита закрывается сразу,
  вход сохраняется, статус `terminating`, затем `archived`.

## Уведомления

| Событие | Кому |
|---|---|
| Аккаунт создан, выдан временный пароль | жильцу (через админа вручную) |
| Документ отклонён | жильцу |
| Документ истекает через 30 / 7 / 0 дней | жильцу и админу |
| Депозит оплачен, статус «Заселён» | жильцу и админу |
| Договор расторгнут | жильцу и суперадмину |
| До возврата депозита 7 / 3 / 1 день, просрочка | суперадмину |
