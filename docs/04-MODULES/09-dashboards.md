# Модуль 9. Дэшборды

## Жилец
1. **Ближайшая уборка** — дата, зона, чек-лист. В день ротации и на следующий день —
   кнопка «Подтвердить ротацию» с загрузкой фото.
2. **Сообщить об отсутствии** — крупная кнопка, три типа.
3. **Счёт к оплате** — сумма, срок, статус, детализация строк.
4. **Депозит** — остаток и последние движения.
5. **Рейтинг** — одно число (если не скрыт настройкой).
6. **Требуется внимание** — просроченные или отклонённые документы, незакрытые шаги заселения.

## Админ дома
1. **Сегодня** — ротации дня с исполнителями и статусами; блок «Требует решения»
   (`needs_reassignment`, неподтверждённые вчерашние).
2. **Оплаты** — выставлено / оплачено / долг за текущий месяц, список должников,
   задачи «Удалёнка».
3. **Рейтинг дома** — средний, худшие и лучшие, сработавшие пороги.
4. **Коммуналка** — статус периода, напоминание заполнить.
5. **Заселение** — жильцы с незакрытыми шагами, истекающие документы.
6. **Календарь ротаций** на неделю с быстрым редактированием.

## Суперадмин
1. **Сеть** — по каждому дому: занятость мест, собрано/долг за месяц, средний рейтинг,
   средняя оценка уборок.
2. **Деньги** — остатки по счетам, поступления и расходы за период, сверка депозитного фонда.
3. **Возвраты депозитов** — расторгнутые договоры с обратным отсчётом 30 дней.
4. **Требует решения** — предложения скидок, спорные штрафы, переоткрытые периоды.
5. **Аудит** — последние значимые действия.

Остальные модули — в боковом меню (десктоп) и в нижней навигации + бургер (мобильный).
