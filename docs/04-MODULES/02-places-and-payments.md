# Модуль 2. Места и оплата

Расчётные правила — `docs/03-BUSINESS-RULES.md` §3.

## Настройка дома
- Список зон: жилые комнаты и общие зоны, с названиями и порядком.
- В жилой комнате — спальные места: ярус (верх/низ), номер, цена по умолчанию.
  Пример: комната №3 — верхнее 65 000, нижнее 70 000.
- Схема дома: список комнат с занятостью мест (кто, до какой даты, цена).

## Назначение места
Модалка: комната → место → цена (предзаполнена ценой по умолчанию, редактируется) → дата начала.
Цена может отличаться индивидуально (льгота, админ — 0).
Смена места: закрывается прежнее назначение, открывается новое; пересечений быть не может.

## Счета
- Автогенерация 1 числа 00:05 для всех активных проживаний.
- Ручное создание счёта: тип, сумма, строки, срок оплаты, комментарий.
- Редактирование строк до полной оплаты; после — только сторно и новый счёт.
- Отметка оплаты: сумма, способ (Kaspi/Наличные), дата, комментарий. Частичная оплата разрешена.
- Пересчёт: кнопка «Пересчитать» перестраивает автоматические строки (проживание, коммуналка,
  штрафы, скидка) по актуальным данным; ручные строки не трогает. Требует подтверждения.

## Экран «Удалёнка»
Список задач админа: жилец, сумма, срок, статус.
Кнопки «Счёт отправлен» и «Оплата получена». Фильтр по дому и месяцу.

## Экраны
- Жилец: список своих счетов, детализация строк, статус, история платежей, флаг «Долг».
- Админ: таблица счетов дома по месяцам, сводка (выставлено / оплачено / долг),
  быстрая отметка оплаты, экспорт CSV/XLSX.
- Суперадмин: то же по всем домам + сравнение домов.
