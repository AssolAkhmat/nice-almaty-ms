# Модуль 10. Бухгалтерия и инвентарь

Правила — `docs/03-BUSINESS-RULES.md` §10.

## Счета (фонды)
- Список счетов: код, название, тип, дом (если привязан), остаток.
- Создание, переименование, архивация. Системные счета не удаляются.
- Произвольный перевод между счетами: сумма, дата, описание.
- Пополнение и изъятие средств.

## Проводки
- Журнал: дата, описание, источник (счёт, депозит, ущерб, ручная), строки дебет/кредит.
- Фильтры по счёту, дому, периоду, типу источника.
- Сторно любой ручной проводки (обратная запись, оригинал не удаляется).
- Отчёты: оборотная ведомость по счетам за период; отчёт «Сверка депозитного фонда»
  (остаток счёта против суммы депозитов активных проживаний, расхождение подсвечивается).
- Экспорт CSV/XLSX.

## Расходы
Категории: аренда, оборудование, химия и расходники, износ, ремонт, прочее.
Поля: дата, сумма, категория, дом (необязательно), счёт списания, описание, чек.

## Калькулятор налогов
Отдельная вкладка: период, доход через Kaspi, оборот эквайринга,
ставки (по умолчанию 3 % и 0,95 %, редактируются).
Результат: налог, комиссия эквайринга, итого к вычету, чистыми.
Разбивка по домам. Кнопка «Провести как расход» (необязательная).
Расчёт справочный и не является налоговой консультацией — надпись в интерфейсе.

## Инвентарь
- Список по домам: наименование, количество, единица, стоимость, ответственный, статус.
- Зона дома у позиции — **необязательная**: кухня, двор, комната. Зона обязана
  принадлежать тому же дому, что и позиция; перемещение в другой дом её снимает.
  Позиция без зоны остаётся нормой — «по дому вообще» (указание владельца,
  21 сентября 2026).
- Приход, перемещение между домами, списание — с историей движений по каждой позиции.
- Инвентаризация: ведомость «по учёту / по факту / расхождение / комментарий»,
  закрытие с автоматической корректировкой количеств.
- Админ видит и ведёт инвентарь только своего дома, суперадмин — всех.
- Отчёты с разбивкой по зонам: список группируется по зонам, выгрузка несёт
  колонку зоны и итог по каждой зоне. Позиции без зоны идут отдельной группой
  «Без зоны» — они не теряются и не приписываются чужой зоне.
- Экспорт CSV/XLSX.
