# Модуль 8. Рейтинг, замечания, штрафы

Правила, дельты и пороги — `docs/03-BUSINESS-RULES.md` §5.

## Действия админа
Форма «Добавить событие»: тип, дата, причина (обязательно), комментарий.
Типы по умолчанию: акт помощи (+2), нарушение (−1), предупреждение (−3),
выговор (−5), строгий выговор (−10). Названия и значения настраиваются.

## Экраны
- **Жилец**: только число (например, «Рейтинг: 62»). Без истории и детализации.
  Суперадмин может глобально скрыть рейтинг от всех жильцов.
- **Админ**: рейтинг каждого жильца, полная история событий, фильтры,
  список сработавших порогов, долги по доп. ротациям, штрафы.
- **Суперадмин**: то же по всем домам, редактор правил, отмена штрафов.

## Редактор правил
Таблица: дельты за оценки, действия админа, пороги вниз (действие + сумма штрафа),
пороги вверх (сумма скидки).
Уровень: сеть (по умолчанию) с переопределением на конкретный дом.
Кнопка «Скопировать правила из дома…».

## Штрафы
- Создаются автоматически при пересечении порога или вручную админом.
- Попадают в ближайший месячный счёт строкой `fine`.
- Отменяются суперадмином: до применения — просто отмена, после — сторно строкой в счёте.

## Скидки
При превышении порога система создаёт предложение. Суперадмин подтверждает.
Далее применяется при генерации каждого счёта, пока рейтинг держится выше порога.
Применяется только наибольшая; проживание не может стать отрицательным.
