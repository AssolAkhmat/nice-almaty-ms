# Модуль 3. Ротации (дежурства)

Формулы и семантика — `docs/03-BUSINESS-RULES.md` §6–§7. Здесь только интерфейс и поведение.

## Настройка
- **Чек-листы**: на каждую зону до двух (обычная и генеральная).
  Поля: название, пункты (список), сколько человек требуется по умолчанию.
- **Группы допуска**: предустановленные (все / парни / девушки / жильцы этой комнаты)
  и произвольные — с явным добавлением и исключением людей.
  Пример: «двор — парни, кроме Азамата».
- **Ряды**: название, тип (общие зоны / комната), день недели, дата первой ротации;
  у комнатного ряда — его комната. Кто участвует и какие зоны убираются, ряд не хранит.
- **Составы и нормы дней** — блок по каждому ряду:
  - состав — места по порядку позиций и дата вступления; прошлые версии перечислены
    строкой; подсказки «места вне рядов» и «место уже в другом ряду» (предупреждение,
    не запрет);
  - норма — зоны по порядку с числом людей на каждую (по умолчанию из чек-листа)
    и дата вступления;
  - предпросмотр на четыре недели вперёд по формуле §6.2 — считается по черновику
    из полей, до сохранения: кто что убирает, где отдых, где дырка;
  - сохранение «с даты» пересобирает нетронутые будущие занятия ряда и перечисляет
    тронутые руками (§6.6).

## Календарь
Три режима: день, неделя, месяц. В каждом — зона, чек-лист, исполнители, статус.
Действия над занятием: перенести на другую дату, заменить исполнителя, отменить,
**снять одного исполнителя с зоны на дату** (двор 2 → 1; последнего не снять —
зону на дату отменяют), **поставить человека на зону** — в дырку или сверх нормы —
с галочкой «списать доп. ротацию». Над периодом: внеплановая ротация (та же галочка),
отмена диапазона дат (каникулы). Кнопка «Сгенерировать расписание до <дата>».

## Дневной режим
Кнопка «Шаблон» → текст: `шапка + дата + все ротации дня с именами + футер`.
Шапка и футер настраиваются отдельно для обычной и генеральной уборки. Кнопка «Копировать».

## Генеральная уборка
Последнее воскресенье месяца; переносится вручную.
Кнопка «Распределить случайно» с учётом групп допуска и количества людей на зону,
результат правится перетаскиванием. Участвуют все, включая админа.

## Задачи админа
Блок «Требует решения» на дэшборде: дырки расписания на вчера и неделю вперёд,
у каждой — причина (пустое место, отсутствие, недопуск с именем стоявшего в очереди,
некого назначить) и три варианта §6.3:
- **поставить** — кандидаты группами: с долгом по доп. ротациям, отдыхающие в этот день,
  остальные жильцы дома; у каждого пометка допуска и занятости в этот день; галочка
  «списать доп. ротацию»;
- **обмен в один ход** — перевести человека с его зоны на дырку, на его зону —
  кандидата или никого;
- **отменить зону на эту дату**.
Система предлагает, админ решает; выбор — обычная правка недели, само предложение
ничего не сохраняет. Там же — вчерашние уборки без отметки.
У жильца на дэшборде — баланс долга по доп. ротациям со знаком (минус — запас).

## Права
Админ управляет расписанием только своего дома. Жилец видит своё расписание
и общий календарь дома в режиме чтения.
