# Модуль 3. Ротации (дежурства)

Формулы и семантика — `docs/03-BUSINESS-RULES.md` §6. Здесь только интерфейс и поведение.

## Настройка
- **Чек-листы**: на каждую зону до двух (обычная и генеральная).
  Поля: название, пункты (список), сколько человек требуется.
- **Группы допуска**: предустановленные (все / парни / девушки / жильцы этой комнаты)
  и произвольные — с явным добавлением и исключением людей.
  Пример: «двор — парни, кроме Азамата».
- **Ряды**: название, тип (общие зоны / комнаты), день недели, дата старта,
  упорядоченный список мест (слотов) и упорядоченный список зон.
  Валидация при сохранении: сумма `people_needed` по зонам ≤ числу слотов.

## Календарь
Три режима: день, неделя, месяц. В каждом — зона, чек-лист, исполнители, статус.
Действия: перетащить ротацию на другую дату, переназначить исполнителя,
отменить, добавить внеплановую, отменить диапазон дат (каникулы).
Кнопка «Сгенерировать расписание до <дата>».

## Дневной режим
Кнопка «Шаблон» → текст: `шапка + дата + все ротации дня с именами + футер`.
Шапка и футер настраиваются отдельно для обычной и генеральной уборки. Кнопка «Копировать».

## Генеральная уборка
Последнее воскресенье месяца; переносится вручную.
Кнопка «Распределить случайно» с учётом групп допуска и количества людей на зону,
результат правится перетаскиванием. Участвуют все, включая админа.

## Задачи админа
Блок «Требует решения»: ротации со статусом `needs_reassignment`
(исполнитель отсутствует или место пустует). Для каждой — «Отменить» или
«Назначить вручную» со списком кандидатов: сначала имеющие долг по доп. ротациям,
затем отдыхающие на этой неделе.

## Права
Админ управляет расписанием только своего дома. Жилец видит своё расписание
и общий календарь дома в режиме чтения.
