# Модуль 4. Подтверждение и оценка ротаций

Правила — `docs/03-BUSINESS-RULES.md` §7.

## Жилец
- На главной: карточка «Ближайшая уборка» — дата, зона, чек-лист.
- В день ротации и весь следующий день — кнопка **«Подтвердить ротацию»**:
  время (по умолчанию текущее), фото (необязательно, несколько), комментарий.
- Оценку не видит никогда.

## Админ
- Список ротаций за день/неделю: зона, исполнитель, статус, время, фото, оценка.
- Отметить за жильца: выполнена, время, оценка 1–10, фото.
- Проставить оценку после подтверждения жильцом.
- Изменить статус: `Выполнена` / `Не выполнена` / `Отменена`.
  `Отменена` не влияет ни на рейтинг, ни на долг.
- Просмотр фото в модалке, скачивание.

## Автоматика
В 23:55 следующего дня неподтверждённые ротации → `Не выполнена`, оценка 1,
событие рейтинга, +1 к долгу дополнительных ротаций. Всё обратимо админом.

## Статистика
- По жильцу: средняя оценка, количество выполненных/пропущенных, динамика по месяцам.
- По дому: средняя оценка, худшие зоны, худшие дни недели.
- По зоне: средняя оценка и частота пропусков.
Экспорт CSV/XLSX.
