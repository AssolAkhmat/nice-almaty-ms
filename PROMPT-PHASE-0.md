# Стартовый промпт для Claude Code

Скопируй целиком в первую сессию Claude Code в свежем репозитории.

---

Ты ведёшь разработку проекта Nice Almaty — системы администрирования сетью студенческих домов.
Работаешь автономно, длинными сессиями, по фазам.

**Шаг 1.** Прочитай полностью, в этом порядке:
`CLAUDE.md`, `docs/00-PRD.md`, `docs/01-ARCHITECTURE.md`, `docs/03-BUSINESS-RULES.md`,
`docs/02-DATA-MODEL.md`, `docs/05-DESIGN-SYSTEM.md`, `docs/07-ROADMAP.md`,
`docs/06-API.md`, все файлы `docs/04-MODULES/`, `docs/08-DECISIONS.md`.
Не начинай писать код, пока не прочитал всё.

**Шаг 2.** Если доступен плагин Superpowers — работай его циклом
(`/superpowers:brainstorm` → `/superpowers:write-plan` → `/superpowers:execute-plan`),
с TDD и code-review субагентами. Если недоступен — держи тот же цикл вручную.

**Шаг 3.** Возьми **Фазу 0** из `docs/07-ROADMAP.md`. Разбей её на таски и запиши
`docs/tasks/PHASE-0.md` чек-листом. Покажи мне план до начала реализации.

**Шаг 4.** Реализуй таски по одному. Один таск = один коммит = зелёный `pnpm verify`.
После каждого таска отмечай чекбокс.

**Шаг 5.** Закончив фазу, обнови `PROGRESS.md` (что сделано, что осталось, на чём споткнулся),
дополни `docs/08-DECISIONS.md` и переходи к следующей фазе тем же порядком.

Жёсткие правила:
- Не выдумывай требования. Нет ответа в `docs/` — выбирай консервативный вариант,
  реализуй и записывай строкой `[ОТКРЫТО]` в `docs/08-DECISIONS.md`.
- Расчётные ядра (`src/domain/*`) пишутся **тестами вперёд** по числовым примерам
  из `docs/03-BUSINESS-RULES.md`. Тест без примера из документа — недостаточен.
- Никаких эмодзи, градиентов, декоративной графики. Дизайн-система — закон.
- Все строки интерфейса через i18n, в трёх локалях сразу.
- Деньги — целые тенге. Даты — `Asia/Almaty`. Прямой `new Date()` в бизнес-логике запрещён.
- Не проси у меня подтверждений на очевидные технические шаги. Спрашивай только тогда,
  когда требование противоречит само себе и оба варианта имеют серьёзные последствия.

Начинай с Шага 1.
